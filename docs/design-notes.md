Kiwi Trader 的应用方式：柔和渐变首屏、悬浮信息卡、三段产品场景与轻量滚动浮现；交互演示仍可操作。支持暂停装饰动效和减少动态效果偏好。图片与业务数据不是展示依赖。

## 为什么产品叙事优先

这份作品集用于产品岗位，所以优先回答用户问题、设计理由与验证方法，而不是罗列技术栈。

- 问题来自个人研究场景的设计假设，不写成已完成用户调研。
- 原型走查与演示逻辑检查是已有证据；真实使用者测试是下一步计划。
- 不编造访谈、用户量、转化、留存或效率提升数据。
- 从正常流程延伸到异常反馈，说明产品如何帮助使用者理解状态与下一步。

## 为什么不是更长的 README

GitHub README 适合快速浏览，但不运行自定义 JavaScript。交互体验放在同一公开仓库的 GitHub Pages，README 保留项目摘要和演示入口。

## 三个合成演示

1. **决策回放：** 正常流程、响应超时、行情过期三种分支；支持单步、自动回放、暂停与重置。
2. **异常对账：** 重复请求不会增加模拟提交次数；补充合成证据后，状态从 unknown 收敛为 reconciled。
3. **数据闸门：** 调整合成快照年龄，观察“数据仍显示”与“新执行被拦截”的区别。60 秒仅为演示阈值。

另有六个可点击的产品决策卡片，以及可展开的验证证据与局限。所有交互都在浏览器内存中运行，刷新后恢复初始状态。

## 视觉与技术选择

- 使用浅色渐变、悬浮卡片与大幅产品场景；真实交互采用轻量浅色界面，减少后台感。
- 页面优先使用中文，英文仅用于辅助标签和工程状态。
- 使用系统字体、自有 SVG 和原生 HTML/CSS/JavaScript；无 CDN、分析脚本和第三方字体。
- 核心内容在关闭 JavaScript 时仍可阅读；交互使用原生按钮、选择器、滑块和折叠元素。
- 展示页使用独立状态机，不导入私有项目源码，不读取任何账户快照。
