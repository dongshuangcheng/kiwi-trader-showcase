# 公开范围与隐私说明

[返回项目首页](../README.md)

## 独立发布，而非公开原仓库

本展示仓库采用独立的 Git 历史，只纳入从零整理的介绍文档与静态架构视觉，不继承原项目的提交、分支、标签或发布制品。

## 公开内容白名单

| 内容 | 处理方式 |
| --- | --- |
| 项目定位与技术栈 | 根据现有实现整理，仅描述通用技术与职责 |
| 架构与工程取舍 | 用概念级说明和新绘制图示表达 |
| 验证思路 | 描述场景，不上传运行日志或私有测试数据 |
| 仓库提交信息 | 使用 GitHub 公开用户名与 noreply 邮箱 |

## 保留在私有环境的内容

- 完整源码、业务实现、策略配置、提示词及内部研究材料。
- 数据库、行情文件、账户快照、订单、成交、持仓和资金信息。
- 凭据、会话、密钥、令牌、系统凭据库导出。
- 日志、备份、故障报告及带有真实数据的截图。
- 本机路径、设备标识、私有服务地址和部署配置。
- 原项目 Git 历史、安装包和其他运行制品。

## 图片与交互边界

页面中的封面是专为展示新建的 SVG，架构图为概念图；没有使用运行界面截图。页面不加载账户数据，不包含表单、分析脚本、追踪像素或业务 API 调用；访问仍受 GitHub 平台自身的服务与隐私政策约束。

## 公开后的边界

公开文档可被访问、复制或建立索引。发布后的删除并不保证第三方副本消失，因此后续更新仍应按文件白名单逐项审核，不从业务工作区自动同步内容。
